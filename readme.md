# 💼 HireHub – Job Portal Web Application

## 📌 Overview

HireHub is a full-stack job portal web application designed to connect job seekers with recruiters on a single platform. It allows users to browse job listings, apply for jobs, and enables recruiters to post and manage job opportunities efficiently.

This project demonstrates real-world full-stack development concepts including authentication, CRUD operations, database integration, and responsive UI design.

---

## 🚀 Features

### 👨‍💼 For Job Seekers:
- User registration and login
- Browse available job listings
- View detailed job descriptions
- Apply for jobs

### 🧑‍💻 For Recruiters:
- Secure authentication system
- Post new job openings
- Edit or delete job posts
- Manage posted jobs

### ⚙️ General Features:
- Responsive UI for all devices
- Secure backend with authentication
- CRUD operations for job data
- Database integration

---

## 🛠️ Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MYSQL

## ⚙️ Installation & Setup

### 1. Clone the repository
git clone https://github.com/NiharikaShokeen/hirehub.git

### 2. Navigate to project folder
cd hirehub

### 3. Install dependencies
npm install

### 4. Run the server
node server.js

### 5. Open in browser
http://localhost:3000
